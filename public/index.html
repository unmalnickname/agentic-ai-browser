Help & Documentation

Getting Started

What is Agentic AI Browser?

Agentic AI Browser is an autonomous web browser that uses AI to navigate and interact with websites. It can perform tasks like searching, clicking, typing, and extracting information automatically.

How to Create a Session

  1. Click on "New Session" in the sidebar
  2. Enter a name for your session
  3. Specify the starting URL
  4. Select your preferred LLM provider and model
  5. Describe your goal for the session
  6. Click "Start Session"

LLM Providers

The Agentic AI Browser supports multiple LLM providers:

  • OpenAI - GPT-3.5 and GPT-4 models
  • Claude (Anthropic) - Claude and Claude Instant models
  • Gemini (Google) - Gemini Pro and Ultra models
  • Ollama - Run local models like Llama, Mistral, etc.
  • DeepSeek - DeepSeek's advanced models
  • OpenRouter - Access multiple models through one API

Troubleshooting

Common Issues

Connection Problems

If you see a "Disconnected" status:

  • Check your internet connection
  • Ensure the server is running
  • Try refreshing the page

Browser Not Responding

If the browser seems stuck:

  • Click the "Stop" button to terminate the session
  • Start a new session
  • Check the logs for any error messages

API Key Issues

If you see authentication errors:

  • Verify your API keys are correctly set in the .env file
  • Ensure you have sufficient credits/quota with your LLM provider
  • Check if the API endpoint is correct for your region
